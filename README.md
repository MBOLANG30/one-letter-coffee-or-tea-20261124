A tiny program that writes the single letter A — for coffee — to entry.txt, answering make.fun's "One Letter: Coffee or Tea" bounty with the louder, punchier drink. Coffee is the first cup of the day and the one people joke they cannot function without; tea, for all its calm, never shouts that loud.

## Run it

```sh
node main.ts
```
